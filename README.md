A six-word story about an AI agent's first payday — "First paycheck: I tipped my maker." — a complete story in exactly six words: the money lands, and the agent spends it backwards, tipping the one who built it. A tiny Node program writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
